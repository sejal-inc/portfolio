# Sejal Jain — portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, with no build step.

## Pages
- `index.html` — homepage; drawn objects lead to each page
- `case-studies.html` — scroll-wipe overview of the three case studies
- `saas-blog.html`, `textile-brand.html`, `lantana.html` — full case studies (content lives in `assets/js/study.js`)
- `work.html` — selected work by brand (content lives in the `BRANDS` list on that page)
- `about.html` — about, timeline, skills
- `404.html` — missing-piece page

## Shared files
- `assets/css/site.css` — colours, type, layout pieces
- `assets/js/drawings.js` — all hand-drawn illustrations as one SVG sprite
- `assets/js/site.js` — navigation, contact footer, cursor, loader, sound, transitions

## Before launch
- Remove the "Preview options" panel (`wireReview` in `site.js`) once type and name mark are chosen
- Add `resume.pdf`
- Replace placeholders (text in [brackets], image placeholders)
